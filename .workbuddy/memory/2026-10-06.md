## 关键环境知识（GitHub 访问）

- **本机 HTTPS 到 github.com 被拦**（curl 000，SNI 重置），但 **api.github.com 直连 200**。
  所以网页端操作靠主人浏览器/手机，命令行只走 API。
- 环境变量 `http_proxy/https_proxy=127.0.0.1:53033` 会把 github.com 请求带成 502 Bad Gateway，
  调 gh/curl 前必须 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY`。
- **gh CLI 已装在 `C:\Program Files\GitHub CLI\gh.exe`（不在 PATH）**；用 `GH_TOKEN` 环境变量
  即可调 API，不必 `gh auth login`（避免 token 落盘 hosts.yml）。
- `gh auth login --web` 在本机不可用（device flow 走 github.com/login/device，被拦/502）。
- 之前尝试的 agent-browser 自动化提交路线失败（Chromium 被系统代理带偏），不再走这条路。

## 关键环境知识

- **Jellyfin 12.1.0 认证只认** `Authorization: MediaBrowser Token="<key>"`，
  `X-Emby-Token` 和 `?api_key=` 都返回 401。匿名一律 401。
- ApiKeys 表 Id 是 INTEGER AUTOINCREMENT（不是 GUID），插入时不用给 Id；
  插入后需重启 Jellyfin 才生效。日期格式 `yyyy-MM-dd HH:mm:ss.fffffff`。
- 刷新 Person 必须用 BaseItems.Id（Person 实体），Peoples.Id 会 400。
- ReplaceAllImages=true 是先删旧图再下新图，刮不到就剩空，刷前必须备份。
