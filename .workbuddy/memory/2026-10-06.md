## 低分演员头像：体检 + 根因修复（commit 93e793a）

体检（tools/avatarscan/avatarscan.py，只读）：库内 2702 张头像，问题 112 张
= 短边 1XX 105 + 0 字节坏图 7。宽度 1XX 共 106。

根因三层：
1. 源头残：gfriends 673 个 id，114 个 jpg 是 1XX；673 个 webp 全 0 字节。
2. 主因：12.1.0 Person 的 BaseItems.Id 与 Peoples.Id 脱钩，图片记录挂 BaseItems.Id
   （2460 人），Peoples.Id 只有 678（673 是插件写的）。LoadTargets 只查 Peoples.Id
   → 全员判缺图 → 覆盖 Metatube 高清图。
3. 无分辨率门槛：TryGetAvatarPath 只 File.Exists。

修复：
- HasImage 查两个 Id + 物理文件兜底
- MinAvatarWidth=300（按短边，不误杀竖图）
- Sources/AvatarGate.cs：手写 JPEG/PNG/WebP 头解析（不能用图像库，原生库会让插件 Malfunctioned）
- provider 同门槛；TryGetAvatarPath 改为"存在且非空"
- 配置页加字段

已部署重启，日志正常。详见 docs/50-低分演员头像-根因与修复.md。

## 部署/环境要点

- PowerShell 工具不回传 stdout，改用 Bash 分步执行。
- 停 Jellyfin 要连 Tray 一起停，否则会被拉起；启动用计划任务避免被会话回收。
- 插件目录备份必须放 plugins/ 树之外。
- Jellyfin API 匿名 401，批量刷新需 API key（当前 ApiKeys 表空）。
